// como funciona
1

Cole o documento

Copie e cole qualquer texto — contrato, artigo, relatório, e-mail. Até 50.000 caracteres.

2

Faça uma pergunta (opcional)

Pergunte qualquer coisa sobre o conteúdo, ou deixe em branco para receber os pontos principais.

3

Análise com Gemini 1.5 Flash

O modelo processa o texto e retorna resumo, pontos principais e a resposta à sua pergunta em segundos.

4

Copie ou compartilhe

Exporte o resultado em JSON ou copie diretamente para usar onde quiser.

💡 Nenhum dado é armazenado permanentemente. Cada análise é independente.
// api docs
GET /api/health
Verifica se o servidor está online e retorna o uptime.
// Resposta { "status": "online", "model": "gemini-1.5-flash", "uptime": "42s" }
POST /api/analyze
Análise completa: resumo + pontos principais + resposta.
// Body { "text": "texto do documento...", "question": "Qual é a conclusão?" // opcional } // Resposta { "resumo": "...", "pontos_principais": ["..."], "resposta": "..." }
POST /api/summarize
Resumo rápido com tipo, sentimento e palavras-chave.
// Body { "text": "texto do documento..." } // Resposta { "resumo": "...", "palavras_chave": ["..."], "sentimento": "positivo | neutro | negativo", "tipo_documento": "artigo | contrato | ..." }
🔒 Rate limit: 10 requisições por minuto por IP. Limite de 50.000 caracteres por request.
